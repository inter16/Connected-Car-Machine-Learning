# 손으로 직접 코드를 구현하는 순서

수업 시간에 직접 코드를 작성하거나 코드의 의미를 설명할 수 있도록, 실행 흐름에 맞춰 구현 순서를 정리했습니다.

## 1. 환경부터 작성: `envs/gridworld.py`

(1) `Action(IntEnum)`으로 UP, DOWN, LEFT, RIGHT의 번호를 정의합니다.

(2) `GridWorld` 클래스의 인스턴스 변수로 `size=4`, `start_state=0`, `terminal_state=15`, `step_reward=-1.0`를 준비합니다. `@dataclass(slots=True)`는 데이터를 가지는 클래스의 생성자 등을 자동으로 만들어 주며, 이 문제에서 강화학습 자체에 필수적인 문법은 아닙니다.

(3) `reset()`은 에피소드 시작 시 상태를 0으로 되돌리고 종료 플래그를 해제합니다.

(4) `next_state(state, action)`은 1차원 상태 번호를 행·열로 바꿔 움직임을 적용합니다. 격자 바깥으로 이동할 수 없도록 좌표를 제한하고, 바뀐 좌표를 상태 번호로 환산합니다. 이 함수는 환경 상태를 바꾸지 않아서 기준값 계산에도 재사용할 수 있습니다.

(5) `step(action)`은 실제 환경 상태를 갱신하고 `(next_state, -1.0, terminated)`를 반환합니다.

격자 바깥을 향한 행동에서 제자리에 머무르면서 보상 -1을 받는 규칙은 **Lecture 2, 11페이지**의 경계 상태 계산 예시에서 확인할 수 있습니다. 단, 그 페이지에서는 `S0`, `S15`가 모두 종료 상태이지만, **HW3에서는 `S0`가 출발 상태이고 `S15`만 종료 상태**입니다. 경계 처리 규칙만 공통으로 사용하고 종료 상태 설정을 혼동하지 않아야 합니다.

## 2. MC 구현: `agents/every_visit_mc.py`

(1) `torch.zeros(16, dtype=torch.float64)`로 상태가치, 반환값 누적 합계를 생성하고 `torch.zeros(16, dtype=torch.int64)`로 방문 횟수를 생성합니다.

(2) 에피소드를 시작한 뒤, 매 행동 직전 상태를 `states` 목록에 저장하고 행동으로 얻은 보상을 `rewards` 목록에 저장합니다.

(3) 종료되면 `discounted_returns()`에서 **뒤에서부터** 반환값을 계산합니다. 미래 반환값을 재사용하므로 중첩 반복문 없이 한 번의 역방향 순회로 계산할 수 있습니다.

(4) `return_sums.index_add_(0, state_ids, returns)`로 동일한 상태가 여러 번 나타나도 각 반환값을 모두 더합니다. `torch.bincount()`는 상태별 방문 횟수를 셉니다.

(5) 지금까지 관측한 반환값 합계를 총 방문 횟수로 나누어 가치함수를 갱신합니다. 이 갱신은 한 에피소드의 끝에서 이루어집니다.

## 3. TD(0) 구현: `agents/td0.py`

(1) 모든 상태의 가치를 0으로 초기화합니다.

(2) 에피소드를 시작하고 한 번씩 행동합니다.

(3) `td0_update()`에서 현재 상태의 값과 다음 상태의 값을 확인합니다. 다음 상태가 `S15`이면 다음 상태 가치 대신 **0**을 사용합니다.

(4) 현재 상태 가치와 `reward + gamma * next_value`의 차이를 계산하여 `alpha`배만큼 수정합니다. **MC와 달리 에피소드 중간에 실행**하는 부분이 핵심입니다.

강의자료 15페이지에서 `alpha=0.01`을 명시하므로 기본 학습률을 이 값으로 설정했습니다.

(5) `S15`에 도달하면 에피소드를 끝내고 `S0`로 돌아갑니다.

## 4. 결과·검증 작성: `utils/analysis.py`, `utils/output.py`

- `analysis.py`는 무작위 정책의 전이확률 행렬을 만들어 벨만 기대 방정식의 선형 연립방정식을 `torch.linalg.solve()`로 풉니다. 학습 알고리즘에 정답을 알려 주는 것이 **아닙니다**. 독립적인 계산 결과와 학습 결과를 비교하기 위한 도구입니다.
- `output.py`에서 `values.reshape(4, 4)`로 행렬을 바꿔 출력합니다. `torch.Tensor`와 `.item()`을 사용하여 값을 출력용 Python 숫자로 변환합니다.
- `cli.py`는 사용자가 MC·TD를 선택하고 반복 횟수·학습률 등을 조정할 수 있게 합니다.
