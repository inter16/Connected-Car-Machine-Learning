## 1-1. Every-Visit Monte Carlo 구현

에이전트는 매 에피소드를 `S0`에서 시작합니다. 매 단계에서 상·하·좌·우 행동을 각각 1/4의 확률로 선택하고, 행동마다 -1을 받습니다. `S15`에 도달하면 그 에피소드를 끝냅니다.

MC는 **에피소드가 끝나야** 각 방문 시점에서 종료할 때까지 얻은 실제 보상의 합을 계산할 수 있습니다. 할인율이 1이므로 다음처럼 계산합니다.

\[
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
\]

```latex
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
```

예를 들어 어느 시점부터 종료까지 행동이 7번 필요했다면 그 시점의 반환값(return)은 -7입니다.

Every-Visit 방식은 **에피소드 안에서 동일한 상태를 여러 번 방문했더라도 각각의 방문 결과를 전부 사용**합니다. `S0→S1→S0→…→S15`라면 첫 번째 S0 방문과 두 번째 S0 방문을 별도 표본으로 셉니다.

\[
V(s)=\frac{1}{N(s)}\sum_{t:S_t=s}G_t
\]

```latex
V(s)=\frac{1}{N(s)}\sum_{t:S_t=s}G_t
```

여기서 합산 범위는 모든 에피소드의 모든 방문 시점이며, `N(s)`는 해당 상태의 **총 방문 횟수**입니다. PDF가 요구한 First-Visit 방식과 혼동하지 않도록 주의해야 합니다. 구현에서는 PyTorch의 `index_add_()`와 `bincount()`로 중복된 상태 방문을 빠짐없이 합산합니다.

## 2-1. TD(0) 구현

TD(0)은 **한 번 행동한 직후** 현재 상태의 가치를 갱신합니다. 에피소드가 끝날 때까지 기다릴 필요가 없습니다. 관찰된 보상과 다음 상태의 현재 가치 추정치를 이용합니다.

\[
V(S_t)\leftarrow V(S_t)+\alpha\left[R_{t+1}+\gamma V(S_{t+1})-V(S_t)\right]
\]

```latex
V(S_t)\leftarrow V(S_t)+\alpha\left[R_{t+1}+\gamma V(S_{t+1})-V(S_t)\right]
```

이 식에서 대괄호 안은 **실제 한 단계 보상과 다음 상태 추정값을 이용한 목표값에서, 현재 추정값을 뺀 차이**입니다. 그 차이의 `alpha`배만큼 현재 추정값을 수정합니다. 다음 상태가 종료 상태 `S15`라면 앞으로 받을 보상이 없으므로 다음 상태 가치는 0으로 둡니다.

**TD(0)의 학습률 `alpha=0.01`은 강의자료 `Lecture 3: Model-Free Prediction` 15페이지에 명시되어 있습니다.** 초기 상태가치 `V(s)=0`, 할인율 `gamma=1`, 각 행동의 확률 `1/4`도 같은 페이지에서 확인할 수 있습니다.

## 2-3. MC Learning과 TD Learning의 차이 (보고서용 답안)

**Monte Carlo(MC) 학습**은 에이전트가 종료 상태에 도달하여 한 에피소드가 끝난 뒤, 각 상태 방문 이후 실제로 받은 보상의 합을 이용해 상태가치를 추정한다. 이번 과제에서 구현한 Every-Visit MC는 동일한 상태를 한 에피소드에서 여러 번 방문한 경우에도 모든 방문을 각각 학습에 반영한다. MC는 미래 가치의 기존 추정치를 사용하지 않고 실제 관찰된 결과를 사용한다는 장점이 있지만, 한 에피소드의 종료를 기다려야 하므로 갱신이 늦어지며 종료까지의 이동 경로 길이가 크게 달라질 경우 추정값의 변동이 커질 수 있다.

**Temporal Difference(TD(0)) 학습**은 한 번 행동하여 보상과 다음 상태가 관찰되는 즉시 현재 상태의 가치 추정치를 갱신한다. 이때 한 단계에서 실제로 얻은 보상에 다음 상태의 현재 가치 추정치를 더하여 학습 목표를 만든다. 따라서 에피소드가 끝나지 않았더라도 학습할 수 있다. 다만 다음 상태의 가치 추정치가 아직 부정확하면 그 오차가 현재 상태의 학습에도 반영될 수 있다. 이처럼 추정된 값을 이용해 다른 추정값을 갱신하는 방식을 **부트스트래핑(bootstrapping)**이라고 한다.

두 방법은 갱신 시점과 사용하는 학습 목표가 다르지만, 이번 과제에서는 모두 **동일한 무작위 행동 정책의 상태가치**를 평가한다. 매 행동에서 -1을 얻고 할인율이 1이므로 종료까지 걸리는 평균 행동 횟수가 길수록 상태가치는 더 작은 음수가 되며, 종료 상태 `S15`의 가치는 0이다. 충분한 표본과 적절한 학습률 조건에서는 두 방법이 같은 정책의 가치함수를 추정하는 것이 목표이지만, 실제 50,000에피소드의 결과는 표본의 무작위성과 TD(0) 학습률 설정 때문에 서로 다를 수 있다. 이 실험만으로 어느 학습 방법이 **항상** 더 빠르거나 정확하다고 결론 내릴 수는 없다. 또한 이번 학습은 고정된 무작위 정책을 평가하는 것으로, 최적 정책을 구하는 학습은 아니다.

| 비교 항목 | Every-Visit MC | TD(0) |
|---|---|---|
| 갱신 시점 | 에피소드 종료 후 | 매 행동 직후 |
| 학습 목표 | 종료까지 실제로 얻은 누적 보상 | 한 단계 보상 + 다음 상태의 가치 추정치 |
| 에피소드 종료 필요 | 필요 | 필요하지 않음 |
| 다른 상태의 기존 가치 추정치 이용 | 이용하지 않음 | 이용함(부트스트래핑) |
| 주요 차이점 | 긴 에피소드의 전체 결과를 기다림 | 짧은 관찰로 바로 갱신하나 추정 오차가 전달될 수 있음 |
